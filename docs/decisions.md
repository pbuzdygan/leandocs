# Decisions and known issues

Significant decisions are ADRs in [`adr/`](adr/). This file keeps the smaller decisions, open owner questions and accepted known issues. Add a row when a decision is worth remembering but too small for an ADR; mark a row superseded instead of deleting it when another decision replaces it.

Older documents and commit subjects mention task IDs (`P<phase>-<nn>`), known issues (`KI-n`) and owner questions (`OQ-n`) from the retired task board `docs/implementation-status.md`. Its last version, including the full work log, is in Git history: `git show 2f34c27:docs/implementation-status.md`.

None.
